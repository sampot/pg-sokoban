# pg-sokoban

瀏覽器**推箱子**：12 關原創小品、復原一步、方向鍵／滑動。純前端；**mobile-first**。

致敬推箱子類型玩法，非商業關卡包復刻。

也可當作 [Playgrounds（遊樂場）](https://play.samkuo.me/) 的 **SAM**（`index.html` 入口）。

## 一鍵開 SAM

```
https://play.samkuo.me/?open=sampot/pg-sokoban&name=推箱子&fresh=1
```

## 試玩（本機）

```bash
npx --yes serve .
```

## 操作

| 操作 | 說明 |
| --- | --- |
| 方向鍵／WASD／滑動 | 移動／推箱 |
| **復原**／Z | 撤銷一步 |
| **重來**／R | 重置本關 |
